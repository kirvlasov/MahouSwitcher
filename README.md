# MahouSwitcher

MahouSwitcher - Windows-утилита для быстрого переключения и исправления текста, набранного в неправильной раскладке.

## Что умеет

- Исправляет последнее введенное слово, строку или выделенный текст.
- Переключает раскладку одной клавишей, по умолчанию через <kbd>CapsLock</kbd>.
- Работает с выбранными в настройках раскладками, а не просто с "следующей" системной раскладкой.
- Поддерживает Cycle Mode для циклического переключения установленных раскладок.
- Может эмулировать системное переключение раскладки через <kbd>Alt</kbd>+<kbd>Shift</kbd> или <kbd>Win</kbd>+<kbd>Space</kbd>.
- Поддерживает сниппеты: автозамену коротких последовательностей на слова или фрагменты текста.
- Показывает индикатор текущей раскладки и живет в трее.
- Хранит настройки в `Mahou.ini` рядом с исполняемым файлом.

## Горячие клавиши

Клавиши можно изменить в окне настроек. Значения по умолчанию:

| Действие | Клавиша |
| --- | --- |
| Исправить последнее слово | <kbd>Pause</kbd> |
| Исправить последнюю строку | <kbd>Shift</kbd>+<kbd>Pause</kbd> |
| Исправить выделенный текст | <kbd>Scroll Lock</kbd> |
| Переключить раскладку одной клавишей | <kbd>CapsLock</kbd> |
| Показать или скрыть окно настроек | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>Insert</kbd> |
| Завершить приложение | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>F12</kbd> |

## Сборка

Нужны Windows, NuGet и MSBuild/Visual Studio с поддержкой .NET Framework 4.5.

```powershell
cd Mahou
nuget restore Mahou.sln
.\buildMahou.cmd
```

Готовый файл появится в `Mahou\bin\Release\Mahou.exe`.

То же самое можно собрать из Visual Studio: откройте `Mahou\Mahou.sln`, выберите конфигурацию `Release|x86` и запустите Build.

## Структура

- `Mahou\Mahou.sln` - решение Visual Studio.
- `Mahou\Mahou.csproj` - WinForms-проект под .NET Framework 4.5.
- `Mahou\Classes` - хуки клавиатуры/мыши, работа с раскладками, конфигурацией и буфером обмена.
- `Mahou\Resources` - иконки приложения.
- `LICENSE.md` - лицензия проекта.

## Настройки

При первом запуске приложение создает `Mahou.ini` в папке с `Mahou.exe`. Чтобы сбросить настройки, закройте приложение и удалите этот файл.

Если в системе меньше двух раскладок, приложению нечего переключать: добавьте нужные языки ввода в настройках Windows.
